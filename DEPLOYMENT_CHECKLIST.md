# Deployment Checklist

Complete this checklist before and after deploying to Render.

## Pre-Deployment Checklist

### 1. Security ✅
- [x] No hardcoded secrets in code
- [x] `.env` files in `.gitignore`
- [x] Docker credentials moved to environment variables
- [x] JWT secret will be auto-generated by Render
- [x] Database password will be auto-generated by Render

### 2. Database ✅
- [x] Schema updated with all required fields
- [x] Migration script created (if needed)
- [x] Default admin user in schema
- [x] Indexes created for performance

### 3. Code Quality ✅
- [x] No hardcoded API URLs
- [x] Environment variables configured
- [x] Error handling in place
- [x] Security middleware active (Helmet, CORS, Rate Limit)

### 4. Configuration Files ✅
- [x] `render.yaml` - Render Blueprint
- [x] `.github/workflows/ci.yml` - GitHub Actions
- [x] `.gitignore` - Updated and complete
- [x] `README.md` - Documentation complete

## Deployment Steps

### Step 1: Push to GitHub

```bash
# Initialize git if not already done
git init

# Add all files
git add .

# Commit changes
git commit -m "Prepare for Render deployment

- Updated database schema with all fields
- Added Render Blueprint configuration
- Added GitHub Actions CI/CD
- Updated .gitignore
- Fixed security issues (moved secrets to env vars)

🤖 Generated with CodeArts Agent"

# Add remote repository
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# Push to GitHub
git push -u origin main
```

### Step 2: Deploy on Render

1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click **"New"** → **"Blueprint"**
3. Connect your GitHub repository
4. Select the repository
5. Render will detect `render.yaml` automatically
6. Review the services:
   - `hbtrade-db` (PostgreSQL)
   - `hbtrade-backend` (API)
   - `hbtrade-frontend` (Web)
7. Click **"Apply"**
8. Wait for deployment (5-10 minutes)

### Step 3: Initialize Database

After all services are deployed:

```bash
# Get database connection string from Render dashboard
# Then run:

psql "YOUR_CONNECTION_STRING" < database/schema.sql
```

Or use Render's built-in PostgreSQL admin:
1. Go to `hbtrade-db` service
2. Click "Connect" → "PSQL"
3. Copy and paste the contents of `database/schema.sql`

### Step 4: Verify Deployment

- [ ] Frontend loads: `https://hbtrade-frontend.onrender.com`
- [ ] Backend API responds: `https://hbtrade-backend.onrender.com/api`
- [ ] Admin login works: `https://hbtrade-frontend.onrender.com/admin/login`
- [ ] Database connected (check backend logs)

### Step 5: Create Admin User

Default admin is created by schema.sql:
- **Email:** admin@hbtrade.com
- **Password:** admin123

**⚠️ IMPORTANT:** Change this password immediately after first login!

## Troubleshooting

### Backend won't start
```bash
# Check logs in Render dashboard
# Common issues:
# - Missing environment variables
# - Database connection failed
# - Port already in use
```

### Frontend build fails
```bash
# Check build logs
# Common issues:
# - Missing dependencies
# - Environment variable not set
# - Next.js build error
```

### Database connection fails
```bash
# Verify:
# - DB_HOST is correct
# - Database is running
# - Credentials are correct
# - SSL is configured
```

### CORS errors
```bash
# Update FRONTEND_URL in backend
# Verify NEXT_PUBLIC_API_URL in frontend
# Check browser console for specific error
```
